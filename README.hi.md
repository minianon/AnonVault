## हिन्दी विवरण (Hindi Specification)

AnonVault एक गोपनीयता-प्रथम व्यक्तिगत कार्यक्षेत्र है जो हैकाथॉन ट्रैकिंग, दैनिक चेकलिस्ट, प्रोजेक्ट पाइपलाइन और रचनात्मक विचारों को एक ही जगह लाता है — सब कुछ एक 4-अंकों वाली PIN लॉक स्क्रीन के पीछे।

> **इसे कहीं सार्वजनिक रूप से डिप्लॉय करने से पहले [सुरक्षा स्थिति](#सुरक्षा-स्थिति) अवश्य पढ़ें।** PIN केवल एक UI गेट है, वास्तविक एक्सेस कंट्रोल नहीं।

### मुख्य मॉड्यूल

| मॉड्यूल | विवरण |
| :--- | :--- |
| **वर्कस्पेस डैशबोर्ड** | पिन किया हुआ होम व्यू। पल्स स्ट्रिप (स्ट्रीक, 7-दिन पूर्णता दर, निर्माणाधीन कॉन्सेप्ट, Review का लिंक), दैनिक कोट, प्रगति बार के साथ चेकलिस्ट स्नैपशॉट, निकटतम हैकाथॉन और उसकी चेकलिस्ट प्रगति, पिन किए गए विचार, तथा स्टेज बैज के साथ पिन किए गए ड्राफ्ट। लाइव `HH:MM:SS` घड़ी भी। |
| **दैनिक चेकलिस्ट** | दैनिक / कार्यदिवस / सप्ताहांत / कस्टम साप्ताहिक और एक-बार वाले कार्य, सबटास्क और प्राथमिकता के साथ। प्रति-तिथि पूर्णता, आज के लिए रद्द करना, **Mark All Done**, हैकाथॉन से वैकल्पिक लिंक, और चुनी हुई तिथि के लिए एक पंक्ति का **दैनिक लॉग**। |

| **आइडिया वॉल्ट** | टैग्स, लिंक्स और इमेज अपलोड के साथ विज़ुअल कॉन्सेप्ट कार्ड्स। विचारों को Project Ideas में **प्रोमोट** किया जा सकता है, जिससे वे सक्रिय वॉल्ट से हट जाते हैं। आर्काइव समर्थित। |

| **Review** | एकमात्र सेक्शन जो इनपुट नहीं, आउटपुट है। 7/30/90 दिनों की पूर्णता दर और स्ट्रीक, क्लिक करने योग्य प्रति-दिन चार्ट, **लगातार छूटने वाले** आवर्ती कार्य, विन रेट के साथ हैकाथॉन फ़नल, और तुलना के लिए संपादन योग्य **लक्ष्य**। |

### कार्यक्षेत्र की विशेषताएं

#### कमांड पैलेट — <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd>
कार्य, हैकाथॉन, विचार, कॉन्सेप्ट और कोट्स — सब में एक साथ खोज, किसी पर भी सीधे जाएं, या टाइप किए गए टेक्स्ट से ही नया कार्य/विचार बनाएं।

#### कीबोर्ड शॉर्टकट
| कुंजी | क्रिया |
| :--- | :--- |
| <kbd>1</kbd>–<kbd>7</kbd> | सेक्शन पर जाएं |
| <kbd>n</kbd> | वर्तमान सेक्शन में नया आइटम |
| <kbd>/</kbd> | वर्तमान सेक्शन की खोज पर फ़ोकस |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>K</kbd> | कमांड पैलेट |

टाइप करते समय और मोडल/पैलेट खुले रहने पर ये निष्क्रिय रहते हैं।

#### अनलॉक अनुक्रम
सही PIN → एक **access-granted ब्रीफ़िंग** जिसमें आज की पूर्णता का प्रोग्रेस डायल, आज के कार्य / इस सप्ताह की हैकाथॉन डेडलाइन / प्रोजेक्ट आइडिया की गिनती, और एक अनुकूल सारांश पंक्ति होती है। कोई भी कुंजी या क्लिक इसे स्किप कर देता है; किसी टाइल पर क्लिक करने से स्किप होकर सीधे उसी सेक्शन में पहुँचते हैं। इसके बाद लॉक लेयर एक अपर्चर की तरह सिकुड़ती है और डैशबोर्ड क्रमबद्ध रूप से प्रकट होता है।

#### अनडू
हैकाथॉन, विचार या कोट डिलीट करने पर टोस्ट में 7 सेकंड के लिए **Undo** मिलता है।

#### आर्काइव
दोनों कैप्चर सेक्शन (Idea Vault, Project Ideas) में आर्काइव सुविधा है — प्रति-कार्ड क्रिया और टूलबार टॉगल, तथा आर्काइव के भीतर होने पर एक स्पष्ट बैनर।

### कैसे शुरू करें

#### 1. डेटाबेस और स्टोरेज

[Supabase](https://supabase.com) पर एक निःशुल्क प्रोजेक्ट बनाएं, फिर:

1. **SQL Editor** में [`supabase/schema.sql`](supabase/schema.sql) चलाएं।
2. माइग्रेशन क्रम से चलाएं — ये हैकाथॉन-लिंक्ड कार्य, प्रोजेक्ट पाइपलाइन, दैनिक लॉग और रेट्रो जोड़ते हैं:
   - [`supabase/migrations/001_hackathon_tasks_and_project_status.sql`](supabase/migrations/001_hackathon_tasks_and_project_status.sql)
   - [`supabase/migrations/002_journal_retro.sql`](supabase/migrations/002_journal_retro.sql)
3. **Storage** पैनल में ठीक `idea-images` नाम का पब्लिक बकेट बनाएं।

> पुराने इंस्टॉल को केवल माइग्रेशन चाहिए। इनके बिना भी ऐप चलता रहता है — नए कॉलम केवल तब भेजे जाते हैं जब उनमें कोई मान हो।

#### 2. एनवायरनमेंट कॉन्फ़िगरेशन

प्रोजेक्ट रूट में `.env` फाइल बनाएं:

```env
VITE_SUPABASE_URL=आपका_supabase_प्रोजेक्ट_url
VITE_SUPABASE_ANON_KEY=आपका_supabase_anon_api_key
VITE_APP_PIN=आपका_4_अंकों_का_सिक्योर_पिन
```

#### 3. लोकल सर्वर चलाएं

```bash
npm install
npm run dev
```

ब्राउज़र में [http://localhost:5173](http://localhost:5173) खोलें।

### सुरक्षा स्थिति

लॉक स्क्रीन क्या करती है और क्या नहीं, यह स्पष्ट रहना ज़रूरी है:

- **`VITE_*` वेरिएबल बिल्ड के समय क्लाइंट बंडल में इनलाइन हो जाते हैं।** `VITE_APP_PIN` और `VITE_SUPABASE_ANON_KEY` दोनों डिप्लॉय की गई JavaScript में पढ़े जा सकते हैं।
- **गेट `sessionStorage` है।** ऑथराइज़ेशन एक `minianon_authorized` फ़्लैग है, जिसे devtools से सेट किया जा सकता है।
- **`schema.sql` हर टेबल पर Row Level Security बंद कर देता है।** RLS बंद होने पर, जिसके पास URL और anon key है वह Supabase REST API से सीधे सभी रो पढ़ और लिख सकता है — ऐप खोलने की ज़रूरत भी नहीं।

PIN को आम नज़रों से बचाने वाली गोपनीयता स्क्रीन मानें, सुरक्षा नहीं। सार्वजनिक डिप्लॉय पर डेटा की चिंता हो तो RLS चालू करें, एक Supabase Auth उपयोगकर्ता बनाएं, और हर पॉलिसी को `auth.uid()` से बाँधें — या पूरे ऐप को होस्ट-स्तरीय एक्सेस कंट्रोल के पीछे रखें।
